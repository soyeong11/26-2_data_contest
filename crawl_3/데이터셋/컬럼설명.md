# 컬럼정의서 — 전력피쳐_지역별_시군구.csv

최종 산출물: `데이터셋/전력피쳐_지역별_시군구.csv` (1행 = 1개 시군구)
생성 스크립트: `compute_power_feature.py` (입력: `지역별_시군구_wide.csv`)

| 컬럼명 | 타입 | 설명 |
|---|---|---|
| 지역코드 | 문자열(5자리) | 시도코드(2자리) + 시군구코드(3자리) |
| 시도코드 | 문자열(2자리) | 법정동 시도 코드 |
| 시도명 | 문자열 | 시도 이름 |
| 시군구코드 | 문자열(3자리) | 법정동 시군구 코드 |
| 시군구명 | 문자열 | 시군구 이름 |
| 용량점수 | 실수, 0~1 | 변전소 "여유 용량" 점수. 전력공급229kV(가중치 0.3) + 전력공급154kV(가중치 0.7) 2029년 기준 여유용량을 지역 내 합산 후 min-max 정규화. **블록 중 하나라도 미수집이면 NaN(빈 값)** |
| 접속점수 | 실수, 0~1 (드물게 음수 가능) | 변전소 "접속 가능성" 점수. 차단기229kV 여유율(0.2) + 차단기154kV 여유율(0.3) + 차단기345kV 여유율(0.5)의 가중합. 여유율 = 여유Bay수/전체Bay수 |
| 전력피쳐 | 실수 | **기본 전력 피쳐.** 용량점수*0.5 + 접속점수*0.5 (가중합, 보완적 결합) |
| 전력피쳐_병목 | 실수, 0~1 | sqrt(용량점수 × 접속점수) (기하평균, 비보완적 결합). 용량·접속 중 하나라도 낮으면 전체가 같이 낮아짐 |
| 용량데이터없음 | True/False | **True면 그 지역의 용량점수·전력피쳐·전력피쳐_병목이 전부 NaN** — "용량이 0"이 아니라 "원본 자체가 미수집"이라는 뜻. 분석에서 반드시 별도 처리 |
| 차단기229kV_여유율 | 실수, 0~1 (드물게 음수) | 22.9kV 차단기 Bay 여유율 (참고용 원본 비율, 접속점수의 구성 요소) |
| 차단기154kV_여유율 | 실수, 0~1 (드물게 음수) | 154kV 차단기 Bay 여유율 |
| 차단기345kV_여유율 | 실수, 0~1 | 345kV 차단기 Bay 여유율 (변전소 1개가 여러 시군구에 중복 반영될 수 있음 — 공급가능지역 텍스트 기반 매핑) |

## 주의할 값
- **빈 값(NaN)**: `용량데이터없음=True`인 행의 용량점수/전력피쳐/전력피쳐_병목. 엑셀/pandas에서 0으로 착각하지 말 것 — "없음"이 아니라 "못 받아온 데이터".
- **음수 값**: 차단기 여유율 컬럼에 간혹 음수가 나올 수 있음. 원본 KEPCO 데이터의 "사용중+사용예정 > 전체대수" 상태를 그대로 반영한 것으로, 코드 오류가 아니라 원본 데이터 이상치. 크롤링 시점마다 실제 전력망 사용 현황이 바뀌므로 **어느 지역에서 나타나는지는 고정이 아님** — 매 산출마다 재확인 필요.

## 참고: 원 테이블(wide) 컬럼 네이밍 규칙
`지역별_시군구_wide.csv`의 원본 컬럼은 `{블록}_{지표}_{집계}` 형식의 한글명을 씀
(예: `전력공급154kV_2029년_합계`, `차단기_변전소기준_22.9kV여유_합계`).
- 블록: 전력공급229kV / 전력공급154kV / 재생e연계 / 차단기_변전소기준(22.9·154kV) / 차단기_공급지역기준(345·154kV)
- 집계: 지역 내 변전소 여러 개 → 합계·최대로 묶음. `{블록}_변전소수`, `{블록}_데이터있음` 컬럼도 존재
- 상세 설명은 `데이터셋/컬럼사전_지역별_wide.csv` 참고 (전체 컬럼 자동 생성 사전)
