# 인수인계 — KEPCO 전력망 기반 전력 피쳐 파이프라인

작성 목적: 오늘 회의 검수용. 무엇을 만들었고, 왜 그렇게 설계했고, 지금 알려진
한계가 뭔지, 앞으로 이 데이터셋을 어떻게 쓰면 되는지 정리.

## 1. 무슨 작업을 했는가

AI 데이터센터 입지 분석 프로젝트의 "전력" 기준 피쳐를 만들기 위해, KEPCO
한전ON 포털(변전소별 여유용량·차단기 Bay 현황)을 크롤링해서 시군구 단위
점수로 집계하는 파이프라인을 구축함.

### 파이프라인 구조 (실행 순서)
1. **`kepco_crawler.py`** — KEPCO 포털에서 원본 데이터 5종 크롤링
   - 전력공급 여유용량 (22.9kV / 154kV)
   - 재생e 연계 여유용량
   - 차단기 여유 Bay (22.9·154kV / 345kV)
   - 지역 마스터(시도→시군구) 2종도 함께 수집
   - 이 원본들을 `지역별_시도_wide.csv` / `_시군구_wide.csv` / `_읍면동_wide.csv`로 집계
2. **`compute_power_feature.py`** — wide 테이블에서 "전력피쳐" 점수 계산
   → `전력피쳐_지역별_시군구.csv` 생성 (컬럼 설명은 별첨 컬럼정의서 참고)
3. **`check_output.py`** — 크롤링 결과 정합성 점검(읽기 전용, 7개 체크 항목:
   코드 불일치, 중복, 항등식, 제주/미수집 여부 등)
4. **`make_workbook.py`** — wide 테이블 3종 + 컬럼사전을 엑셀 1개 파일로 합침
   (사람이 훑어볼 때 용도)

### 전력피쳐 설계 로직
전력 공급 여력을 "용량점수(여유 용량이 있는가)"와 "접속점수(연결할 설비가
있는가)" 두 축으로 나눠 계산 — 용량이 있어도 Bay가 없으면 연결 불가능하고,
Bay가 있어도 용량이 없으면 공급 불가능하므로 대체 관계가 아니라 둘 다 필요한
관계로 봄. 두 점수를 가중합(전력피쳐)과 기하평균(전력피쳐_병목) 두 방식으로
결합해서 같이 제공 — 등수 차이가 크게 나는 지역은 "용량은 있는데 접속이 안
되는" 식의 불균형 지역일 가능성이 높아 참고용으로 같이 봄.

**가중치는 전부 설계자 제안값(전문가 검토 전)**이며, 논문에서 가져온 수치가
아님. 팀이 인용한 Fuzzy-AHP 논문(이기수·정준호)은 전력/신재생/재해/네트워크/
냉각 5대 기준 간 비중만 다루고, 전력 내부의 전압별·용량-접속 비중까지는
다루지 않는 것으로 판단되어 공학적 근거로 별도 설계함 — **회의에서 검수가
필요한 부분은 바로 이 가중치**. (상세 근거는 `compute_power_feature.py` 파일
상단 주석 참고)

## 2. 작업 중 발견/해결한 문제

| 문제 | 원인 | 처리 |
|---|---|---|
| 일부 시군구 행이 지역마스터에 아예 없음 | 재시도 로직 부재로 일부 시도 조회가 빈 응답으로 끝남 | 크롤러에 3라운드 재시도(5초/10초/대기) 로직 추가 후 재크롤링 → 해결 |
| 세종 일시적 공백 | 크롤링 1회차 때 서버가 일시적으로 빈 응답 | 재크롤링으로 해결 확인 (API 직접 호출로 정상 응답 사전 확인) |
| **부산·대구·울산·경북·경남·제주 6개 시도 전력공급 여유용량 공백** | KEPCO 포털 자체가 이 6개 시도는 전력공급 여유용량 조회를 지원하지 않음 (지역마스터·차단기 조회는 정상, 전력공급 조회만 빈 응답) — 실제 사이트 화면에서도 "검색결과가 없습니다" 확인됨 | **코드로 해결 불가, 구조적 데이터 공백.** `용량데이터없음=True`로 표시해 분석 단계에서 구분 가능하게 처리 |
| 일부 지역 차단기 여유율 음수 | 원본 "사용중+사용예정 > 전체대수" 데이터 그대로 | 코드 수정 없음(원본 이상치), 매 크롤링마다 재확인 필요 |

## 3. 이 데이터셋, 앞으로 어떻게 쓰면 되는가

- **분석 단위**: 시군구(최소 단위). 필요시 시도 단위 집계본(`지역별_시도_wide.csv`
  기반)도 동일 로직으로 만들 수 있음.
- **메인 컬럼**: `전력피쳐`(기본, 보완적 결합) 또는 `전력피쳐_병목`(비보완적
  결합) 중 분석 목적에 맞는 쪽을 선택. 두 컬럼 다 돌려보고 상위 랭킹이 크게
  안 바뀌면 `전력피쳐`로 확정해도 무방.
- **6개 공백 시도 처리 필수**: `용량데이터없음=True`인 행(부산/대구/울산/
  경북/경남/제주)은 전력피쳐가 전부 NaN이므로, 이 지역들을 포함한 전체
  랭킹에 그대로 넣으면 안 됨. 둘 중 하나로 처리:
  1. 분석 대상에서 제외하고 각주 처리, 또는
  2. 접속점수만으로 별도 랭킹을 만들어 "참고용"으로 병기
  (회의에서 결정 필요 — 아직 미정)
- **다음 결합 단계**: 이 전력피쳐는 5대 기준(전력/신재생/재해/네트워크/냉각)
  중 "전력" 하나의 점수. 팀 전체 Fuzzy-AHP 가중치로 다른 기준들과 합칠 때는
  이 `전력피쳐`(또는 `_병목`) 컬럼을 그대로 투입하면 됨.
- **재현성**: `kepco_crawler.py` → `compute_power_feature.py` 순서로 재실행하면
  동일 로직 재적용됨. 단, KEPCO 원본 데이터 자체가 시점마다 바뀌므로 숫자가
  똑같이 나오진 않음(바뀌는 게 정상).
