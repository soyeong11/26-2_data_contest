## 2. 공유용 파일 컬럼

| 컬럼 | 정의 |
|---|---|
| `시군구코드` | **병합 키.** 5자리, `행정시군구_기준행.csv`와 코드·순서 동일 |
| `지역코드` | 시군구코드와 같은 값(v2 호환용) |
| `시도명`, `시군구명` | 2026 행정구역 명칭 |
| `분석대상` | True 174. 용량 자료가 있는 지역 |
| `전력피쳐` | **메인 지표.** 0.5×용량점수 + 0.5×접속점수 (0~1, 클수록 유리). 분석대상 외 빈칸 |
| `전력순위` | 분석대상 174개 내 순위(1=가장 유리) |
| `용량점수` | 2029년 0.1×norm(22.9kV 단일변전소 최대 여유) + 0.9×norm(154kV 단일변전소 최대 여유). norm=174개 기준 min-max |
| `접속점수` | 현재 차단기 여유율 0.1×22.9kV + 0.25×154kV + 0.65×345kV(음수 0 절단) → 174개 기준 min-max |
| `수용가능_1GW` | 시설 1,250MW(1GW IT × PUE 1.25) 수용 판정: 154kV 최대 여유 ≥1,250MW **또는** 345kV 여유 Bay ≥1. 256개 전체 판정(영남 포함) |
| `수용가능_0.5GW` | 625MW 기준: 154kV 최대 여유 ≥625MW 또는 345kV 여유 Bay ≥1 |
| `판정근거` | `154kV≥1250MW` / `345kV 여유Bay` / `154kV≥625MW(0.5GW만)` / `미충족` / `응답없음` |
| `전력피쳐_2032`, `전력순위_2032` | 장기 시나리오(용량만 2032년) |
| `참고등급` | True 81: 용량 자료 없는 지역(영남·제주 77 중 울릉 제외 76 + 무응답 5) |
| `참고_접속순위` | 참고등급 내부의 접속점수 단독 순위. **본 순위와 섞지 말 것** |
| `용량데이터없음` | KEPCO 미공개 6개 시도(부산·대구·울산·경북·경남·제주) |
| `전력공급_무응답` | 차단기 변전소는 있으나 전력공급 여유용량 응답이 없는 5곳 |
| `음수여유율` | 원자료 여유율 음수(미추홀구·연수구·부천시 원미구·고창군) |
| `345kV_상위지역공유` | 화성시 345kV 값을 4개 구에 복제한 행 |

울릉군은 전력공급·차단기 응답이 모두 없어 분석대상·참고등급 어디에도 속하지 않음(`변전소응답없음`, 상세 파일).

## 3. 결과 요약

- 분석대상 174 중 `수용가능_1GW` 88곳, 참고등급 81 중 47곳 — **모두 345kV 기준으로 통과.** 154kV 단독으로 1GW를 넘는 곳은 없음.
- v3 상위(1GW 통과): 서산(1), 당진(2), 오산(4), 화성 동탄구(6), 제천(8), 양양(10), 강릉(11), 군산(15)
- 상위 10 중 신안(3)·순창(5)·보령(7)·부여(9)는 154kV 여유는 크지만 345kV 여유 Bay가 없어 1GW 미충족.
- 군산은 v2 2위 → v3 15위: 154kV 변전소 14개 합계 2,615MW였으나 단일 최대는 580MW.
- 확정 부지 점검: 세종 42위(1GW 미충족), 동해 78위(충족), 울산 울주군 참고 16위·중구 참고 7위(충족).

## 4. 민감도 (기준 = v3, 174개)

| 변형 | ρ | 상위10 유지 |
|---|---|---|
| 결합·154kV·345kV 비중 ±20% | 0.978~0.992 | 7~9 |
| 22.9kV 용량 가중치 0 | 0.992 | 9 |
| 접속 정규화 없음(v2 방식) | 0.974 | 7 |
| 용량 합계(v2 방식) | 0.925 | **4** |
| 연도 2028 / 2030 / 2032 | 0.959 / 0.935 / 0.770 | 5 / 8 / 3 |
| 정규화 log / 백분위 | 0.900 / 0.928 | 6 / 7 |
| 기하평균(병목) | 0.703 | 7 |
| EWM | 0.924 | 6 |
| v2 전력피쳐 | 0.969 | 4 |

해석: 가중치 변화에는 안정적이나, **"합계 vs 최대" 선택과 기준연도가 상위권을 크게 바꿈.** 최대 MW는 소수 변전소 값으로 결정되어 v2보다 연도 변화에 민감해짐(2028 상위10 유지 v2 8 → v3 5).

## 5. 한계 (보고서용)

1. **345kV 판정의 근거 수준:** 여유 Bay 1개가 1GW 수전을 보장한다는 기술 근거는 미확보. 345kV 공급지역은 시 단위 텍스트라 한 변전소가 여러 시군구에 동시에 반영됨 → 판정이 관대함(분석대상 절반이 통과). 1차 필터로만 사용하고 확정 판정으로 쓰지 말 것.
2. 시점 차이: 용량은 2029 전망, 접속은 현재 차단기 현황.
3. 공유 변전소: 여러 후보지 동시 선정 시 같은 변전소 여유를 중복 사용할 수 없음.
4. 참고등급 81곳은 용량 없이 접속점수만으로 순위화 — 본 순위와 비교 불가.
5. 무응답 5곳의 원인(KEPCO 공시 누락 vs 크롤링)은 미확정. 순천은 차단기 변전소 8개로 실제 0일 가능성 낮음.
6. 가중치는 도메인 논리 기반 제안값(문헌 수치 아님).
7. 22.9kV 2026~27년 전 지역 0의 의미는 미확인.
